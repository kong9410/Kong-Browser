# desktop — Kong Browser (PC, Electron)

레시피가 있는 커뮤니티 페이지를 통일된 화면으로 보여주는 PC 브라우저입니다. 설계는 [docs/DESIGN.md](../docs/DESIGN.md) 8-1절.

## 실행

Node 20 이상. Electron 은 **39.8.10 으로 고정**했습니다. 40 이상은 설치 스크립트가 Node 22.12 이상을 요구하는데, 이 PC 는 Node 20.11 입니다. Node 22 LTS 로 올리면 최신 Electron 으로 바꿀 수 있습니다.

```bash
npm install
```

개발 실행 (빌드 후 앱 실행)

```bash
npm start
```

Windows 설치 파일 만들기 → `release/Kong Browser Setup <버전>.exe`

```bash
npm run dist
```

단위 테스트 (구현할 때마다, Electron 없이 1초 안쪽):

```bash
npm test
```

통합 테스트 (큰 작업을 마쳤을 때나 커밋 전에 한 번): 실제 앱을 띄워 툴바를 조작합니다. 주소 입력, 게시판/글, 댓글 페이지, 사이트 버튼, 원본 보기, 깨진 레시피 배너를 확인하고, 설치본이 있으면 설치본도 확인합니다. 스크린샷은 `out/` 에 저장됩니다.

```bash
npm run e2e
```

## 사용법

| 기능 | 방법 |
|---|---|
| 창 맨 위 | Chrome 처럼 제목 표시줄 없이 탭 줄이 맨 위. 탭 줄 빈 곳을 끌면 창 이동, 두 번 누르면 최대화. 최소화/최대화/닫기는 탭 줄 오른쪽 끝 |
| 새 탭 | 탭 줄의 [+], `Ctrl+T` |
| 탭 아이콘 | 사이트가 알려준 아이콘 → 없으면 그 사이트의 /favicon.ico → 그것도 없으면 기본 아이콘. 시작 페이지·방문 기록·북마크 관리는 앱 아이콘 |
| 오른쪽 dock | 국내 주요 커뮤니티 15곳 바로가기 (루리웹, 디시인사이드, 에펨코리아, 더쿠, 클리앙, 뽐뿌, 인벤, MLB파크, 오늘의유머, 보배드림, 웃긴대학, 인스티즈, 네이트판, 82쿡, SLR클럽). 클릭 = 지금 탭, `Ctrl+클릭`·가운데 클릭 = 뒤쪽 새 탭. 지금 보는 사이트는 강조 |
| 탭 닫기 | 탭의 ×, 가운데 버튼 클릭, `Ctrl+W` (마지막 탭을 닫으면 창이 닫힘) |
| 탭 이동 | 탭 클릭, `Ctrl+Tab` / `Ctrl+Shift+Tab`, `Ctrl+1`~`8` (그 번째 탭), `Ctrl+9` (마지막 탭) |
| 탭 순서 바꾸기 | 탭을 끌어서 원하는 자리에 놓기 |
| 탭 복원 | 다시 실행하면 지난번 탭들과 보던 탭이 그대로 열림 (마지막 탭을 직접 닫고 끝냈으면 새로 시작) |
| 북마크 | 주소창 오른쪽 ☆ 또는 `Ctrl+D` 로 추가/삭제. 이미 북마크된 페이지에서 ★ 를 누르면 폴더로 이동 / 삭제 / 관리 메뉴. 북마크 바(`Ctrl+Shift+B` 로 숨기기/보이기): 클릭 = 지금 탭, `Ctrl+클릭`·가운데 클릭 = 뒤쪽 새 탭, 오른쪽 클릭 = 새 탭에서 열기 / 삭제. 시작 페이지에도 표시 |
| 북마크 폴더 | 북마크 바에 폴더가 먼저 보이고, 누르면 안의 북마크 메뉴 (`Ctrl+클릭` = 뒤쪽 새 탭, "모두 새 탭에서 열기"). 북마크 오른쪽 클릭 → 폴더로 이동. **북마크 관리**(`Ctrl+Shift+O`, 시작 페이지의 "북마크 관리"): 폴더 만들기·이름 바꾸기·삭제(안의 북마크는 북마크 바로), 북마크 이름 바꾸기·폴더 옮기기·삭제. 폴더는 한 단계 |
| 방문 기록 | 툴바 오른쪽 시계 버튼 또는 `Ctrl+H`. 날짜별 목록, 검색, 하나씩 삭제, 모두 삭제(두 번 눌러 확인). 시작 페이지에 최근 방문 8개 |
| 새 창으로 여는 링크 | 새 탭으로 열림 (target=_blank, window.open). `Ctrl+클릭` 은 뒤쪽 탭으로 |
| 주소 이동 / 검색 | 주소창에 입력 후 Enter (주소가 아니면 Google 검색) |
| 자동완성 | 주소창에 입력하면 아래에 목록: 첫 줄은 입력한 그대로(이동/검색), 그 아래 북마크(★, 폴더 이름 표시)와 방문 기록. 제목·주소·폴더 이름으로 찾고, 북마크·자주·최근 방문 순. `↑` `↓` 로 고르고 `Enter`, `Esc` 로 닫기, 마우스로 눌러도 됨 |
| 주소창으로 이동 | `Ctrl+L` 또는 `F6` |
| 뒤로 / 앞으로 | `Alt+←` / `Alt+→` |
| 새로고침 | `F5` 또는 `Ctrl+R` |
| 원본 화면 ↔ 통일 화면 | 오른쪽 위 [원본 보기] (레시피가 있는 사이트에서만 보임) |
| 왼쪽 메뉴 | 통일 화면 왼쪽 열. 루리웹은 상단 메뉴(PS5·XSX·PC…) + 게시판 메뉴, 디시는 상단 메뉴(갤러리·마이너갤…) + 최근 방문 갤러리. 메뉴 열의 [접기] / [☰ 메뉴] 로 접고 펴기 (기본 펼침, 마지막 상태를 `settings.json` 에 기억) |
| 오른쪽 열 | 루리웹은 게시판 BEST 글 목록, 디시는 전체글·개념글·공지와 말머리 (목록 페이지). 창이 좁으면 본문 아래로 |
| 맨 위 / 맨 아래 | 오른쪽 아래 ↑ ↓ (모든 페이지, 필요할 때만 보임) |
| 게시판 목록으로 | 글 본문 아래, 댓글 위의 [목록] (사이트의 원래 버튼. 디시는 "전체글") |
| 개발자 도구 (페이지) | `F12` |

주소창 왼쪽 표시: **통일 화면** = 재배치됨, **원본** = 원본 보기 중이거나 레시피가 깨져 원본으로 대체됨. 깨진 경우 주황색 배너가 함께 뜹니다.

화면은 항상 밝은 모드입니다. Windows 가 다크 모드여도 제목 표시줄, 통일 화면, 사이트 모두 밝게 보입니다 (`src/main.ts` 의 `nativeTheme.themeSource`). 다크 모드 선택은 나중에 설정 화면에 추가합니다.

지원 사이트: 루리웹(PC/모바일), 디시인사이드(일반·마이너 갤러리). 레시피는 `../recipes/`.

고장 보고: 판정이 broken/degraded 이면 `%APPDATA%\Kong Browser\reports.jsonl` 에 한 줄씩 쌓입니다. 사이트·레시피 버전·실패한 필드만 담고, 글 내용은 넣지 않으며 URL 의 숫자는 `*` 로 가립니다. 같은 고장은 1시간에 한 번만 기록합니다. M4 에서 서버로 보냅니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/main.ts` | 창, 탭(탭마다 WebContentsView 하나, 원본 보기 상태도 탭마다), 단축키, 레시피 로드, 판정 수신 |
| `src/preload-page.ts` | 웹페이지 preload. `transformer/src` 엔진을 그대로 번들해서 격리된 world 에서 `kong.boot` / `kong.bootMenu` |
| `src/page-tools.ts` | 모든 페이지에 붙는 맨 위/맨 아래 버튼 (Shadow DOM) |
| `src/preload-ui.ts` | 툴바에 노출하는 최소 API |
| `src/dock.ts` | dock 사이트 목록, 지금 사이트 판별 (순수, `dock.test.ts`) |
| `src/favicon.ts` | 탭·북마크 아이콘 고르기 (순수, `favicon.test.ts`) |
| `src/suggest.ts` | 주소창 자동완성 후보·순위 (순수 함수, `suggest.test.ts`) |
| `src/bookmarks.ts` | 북마크·폴더 조작 (순수 함수, `bookmarks.test.ts`) |
| `src/preload-suggest.ts`, `src/ui/suggest.*` | 페이지 위에 겹쳐 뜨는 자동완성 목록 창 |
| `src/store.ts` | 탭 세션·북마크·방문 기록 저장 (`%APPDATA%/Kong Browser/session.json`, `bookmarks.json`, `history.json`, 이 PC 에만) |
| `src/ui/` | 탭 줄·툴바·북마크 바, 시작 페이지(`start`), 방문 기록(`history`), 북마크 관리(`bookmarks`), 공용(`pages`) |
| `scripts/build.mts` | esbuild 로 `dist/` 빌드, `../recipes` 복사 |
| `scripts/e2e.mts` | Playwright 로 앱 자동 테스트 |

레시피를 고친 뒤에는 `npm start` 로 다시 빌드하면 반영됩니다(지금은 앱에 내장. M4 에서 서버 동기화).
